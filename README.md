# GlowSonic

GlowSonic is a Lyrion Music Server plugin for browsing and playing music from Subsonic/OpenSubsonic servers such as Navidrome, Gonic, Airsonic, and compatible forks.

## Features

- Browse artists, albums, genres, playlists, and starred items
- Search songs, albums, and artists
- Stream through a custom LMS protocol handler
- Cover art, favorites, and basic scrobbling support

## Install

Copy `Plugins/GlowSonic` into your LMS `Plugins` directory and restart LMS.

Configure the server URL, username, and password from the LMS plugin settings page.

## Status

Work in progress. Tested primarily with Navidrome and LMS 9.x.

## Disclaimer

This project is vibecoded: built quickly, tested pragmatically, and likely to have rough edges. Review changes before running it on an important LMS setup.
